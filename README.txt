محتويات المجلد / Package Contents:
--------------------------------------------------------------------------------

1. ملفات التثبيت الرسمية (Windows Installer):
   - FileNest-Setup.exe (المثبت الرئيسي للبرنامج - ينصح بربط زر "تحميل لنظام ويندوز" به)
   - FileNest-Setup-x64.exe (نسخة طبق الأصل للمثبت بمعمارية 64-bit)
   - FileNest-Setup.dll (ملف المحرك والمكتبات الأساسية للمثبت والمضمن بداخله كامل التطبيق)
   - FileNest-Setup.runtimeconfig.json & FileNest-Setup.deps.json (ملفات بيئة التشغيل)
   - FileNest-Setup.zip (حزمة مضغوطة متكاملة للمثبت جاهزة للتحميل المباشر من الموقع)

2. ملفات النسخة المحمولة المباشرة (Portable / Direct Run):
   - FileNest.exe (الملف التنفيذي لتشغيل البرنامج مباشرة دون الحاجة للتثبيت)
   - FileNest.dll + FileOrganizerPro.Core.dll + FileOrganizerPro.Infrastructure.dll
   - Microsoft.Data.Sqlite.dll + مكتبات محرك SQLite المحلي
   - runtimes\ (مكتبات بيئة تشغيل Windows x64 Native C++)
   - branding\ (الشعارات والأيقونات الرسمية بدقة عالية)
   - Portable\ (مجلد يحتوي على النسخة المحمولة بكامل ملفاتها معزولة)
   - FileNest-Portable.zip (ملف ZIP يحتوي على النسخة المحمولة جاهز للتحميل)

3. ملفات التحقق والأمان:
   - SHA256SUMS.txt (بصمات التجزئة والتشفير SHA-256 لكافة الملفات لضمان سلامتها)

--------------------------------------------------------------------------------
طريقة الاستخدام مع منصة MANUS:
--------------------------------------------------------------------------------
1. لرفع ملف التحميل الرئيسي لموقع MANUS:
   - يمكنك رفع ملف: FileNest-Setup.zip أو FileNest-Setup.exe
   - ووضع رابط الزر الرئيسي في الموقع: "Download for Windows 10 / 11"

2. لزر النسخة المحمولة (Portable Edition):
   - يمكنك رفع ملف: FileNest-Portable.zip
   - ووضع رابط الزر: "Download Portable (No Install)"

3. مواصفات الإصدار للظهور في الموقع:
   - اسم البرنامج: FileNest (فايل نست)
   - الإصدار: 1.0.0 LTS Public Edition
   - الترخيص: مجاني 100% (Freeware) بدون اشتراكات أو تسجيل دخول
   - اللغات المدعومة: العربية، الإنجليزية، الإسبانية، الفرنسية، الألمانية
   - أنظمة التشغيل: Windows 10 / Windows 11 (64-bit)
